# F05 weight tracker (v2.3 pass 5 of 12)

## Material changes from v2.2

F05 is now **opt-in not opt-out** and the **reference band is default-off** (v2.2 had both default-on).

## Highest-leverage finding

**Move F05 from Pro to Free tier** (SED-F05-022). Gating eating-disorder-protective infrastructure (hide-the-chart, write-only, BEAT signposting) behind a £4.99 paywall is the wrong shape. The user who most needs the protection should not have to pay to access it. CTO/CSO decision required before v1.0 lock. If F05 remains Pro, SED-F05-008/011/013/021 MUST be free-tier accessible.

## v1.0 additions

- SED-F05-011 opt-in onboarding gate (equal visual weight: "Set up" / "Not for me — hide this from Tools")
- SED-F05-012 5-step wizard (units / pre-pregnancy weight optional / display preference / show reference band default-OFF / wellbeing prompt with BEAT + PANDAS)
- SED-F05-013 write-only mode with no echo on save
- SED-F05-014 reference band default-OFF + relabel
- SED-F05-015 per-entry notes
- SED-F05-016 frequency framing (no nudges — F05 never sends weight reminders; SED-UX-027 AP-16 codified)
- SED-F05-017 widget privacy guarantee

## v1.0.x additions

- SED-F05-018 PDF weight-record export
- SED-F05-019 hyperemesis mode (with Pregnancy Sickness Support signposting and softened SED-F05-009 wording)

## Sensitive default onboarding wording

Full first-launch flow with each screen's copy preserved in the agent transcript. Key prompt: *"Logging your weight is optional. Some people find it useful; others find it stressful. You can turn this off any time."* — and "Not for me — hide this from Tools" is the same visual weight as "Set up", not de-emphasised.

Sources: NICE NG201 (de-emphasises routine pregnancy weighing); BEAT eating-disorder-and-pregnancy guidance; Tommy's body-image content; Levinson et al. 2024 systematic review on diet/fitness apps and body image; PMC perinatal eating-disorder qualitative studies.
