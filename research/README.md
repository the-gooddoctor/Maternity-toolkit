# Research artefacts — Seed PRD v2.0 → v2.1

These five reports were produced by parallel research agents on 15 May 2026 to inform the v2.1 revision of the Seed Maternity Toolkit PRD. They are preserved here for traceability — every v2.1 change can be traced back to a specific finding in one of these reports.

| File | Agent | Focus |
|---|---|---|
| `01_regulatory_clinical_validation.md` | Regulatory and clinical | UK MDR / MHRA position, NICE guideline IDs, ICO Children's Code, charity helpline numbers, Apple/Google health-app policies |
| `02_competitive_market_analysis.md` | UK competitive market | Top 10 UK pregnancy apps in 2026, pricing, the September 2025 Flo class-action settlement, UK birth statistics, ASO keywords |
| `03_technical_stack_validation.md` | Technical stack | Expo SDK 55 / RN 0.83 / MMKV v4 / 16 KB page-size, critical code bugs (encryption key, timer hook, persist middleware), New Architecture |
| `04_ux_accessibility_sensitivity.md` | UX, accessibility, sensitivity | WCAG 2.2 AA gaps, colour contrast failures, inclusive language, pregnancy-loss charity expansion, partner-mode inclusivity, postnatal scope mismatch |
| `05_gap_analysis_completeness.md` | Gap analysis | Customer support model, ToS, QA, CI/CD, release management, GDPR Article 20, OTA policy, edge cases, roadmap |

See `PRD_v2_0_to_v2_1_CHANGELOG.md` at the repo root for the synthesised delta.
